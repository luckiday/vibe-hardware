# Ordering this board at JLCPCB

Generated by `skills/vibe-pcb/scripts/fab_export.sh`. Regenerate any time:

```bash
cd kicad
./route_fr.sh                                              # board must gate DRC 0/0 first
../../../../skills/vibe-pcb/scripts/fab_export.sh macropad-fr SW1 SW2 SW3
```

The three refs on the end are the MX keys — they are through-hole and stay out
of the SMT files on purpose.

**Nothing here has been fabricated.** §5 lists what to settle first.

## 1. The package

`kicad/fab/` after a run:

| file | what it is |
|---|---|
| `macropad-fr-gerber-jlcpcb.zip` | 12 files: F/B copper, mask, paste, silk, `Edge_Cuts.gm1`, `PTH.drl`, `NPTH.drl`, job file |
| `macropad-fr-CPL-jlcpcb.csv` | 19 SMT placements — `Designator, Mid X, Mid Y, Layer, Rotation` |
| `macropad-fr-BOM-jlcpcb.csv` | 14 lines, every one with an LCSC number |

Coordinates in the CPL are in the same absolute frame as the gerbers (the
drill is exported with `--drill-origin absolute` for exactly this reason), so
JLCPCB aligns them to the outline without an offset.

## 2. Board options

| field | value | why |
|---|---|---|

| Layers | **2** | |
| Thickness | **1.6 mm** | `constraints.yaml` `board.outline.t`; the enclosure's standoffs assume it |

| Surface finish | HASL is fine; **ENIG** if you want the mic's LGA pads flat | the ICS-43434 is a 6-pad LGA on 0.6 × 0.5 mm lands |

## 3. Upload

1. **Gerber upload** — the `.zip`. Do **not** import the KiCad project into
   EasyEDA/LCEDA: its importer drops footprints and mangles refdes.
2. Turn on **SMT assembly**, top side, then upload the **BOM** and the **CPL**.
3. JLCPCB matches each LCSC number and shows a **placement preview**.

### Check the rotations in that preview — this is the step that ruins boards

KiCad and JLCPCB do not always agree on a part's zero-rotation, and the
mismatch is per-footprint, silent, and only visible in the preview. Two-pad
passives are symmetric and safe; everything below is not. Check each against
this table, which is generated from the board itself:

| ref | part | pin 1 should sit … | CPL rotation |
|---|---|---|---|
| U1 | ESP32-S3-WROOM-1 | north-west of centre | 0° |
| U3 | AP2112K-3.3 (SOT-23-5) | north-west | 0° |
| D1 | USBLC6-2SC6 (SOT-23-6) | north-west | 0° |
| U4 | ICS-43434 mic | south-east | 180° |
| D4 | LED, red (pin 1 = **cathode**) | east | 180° |
| J1 | USB-C, pad A1 | north-east | −90° |
| SW4 / SW5 | TS-1187A | north-west | 0° |

"North" is toward the WROOM/antenna edge, "east" toward the test pads. If the
preview disagrees for a part, fix that row's `Rotation` in the CPL and
re-upload — do not accept a preview you have not read.

## 4. What you still solder yourself

**SW1–SW3, the three MX key switches.** Through-hole, and no Cherry-MX-style
switch is in JLCPCB's assembly library. Six joints total. They are already
excluded from the CPL, so the assembled board arrives with the pads open.

Everything else — 19 placements including the USB-C, the module, the mic and
both buttons — is machine-placed.

## 5. Before you press order

| # | check | why it is not settled here |
|---|---|---|
| E4 | trace widths 0.5 mm power / 0.25 mm signal | sized by rule of thumb; VBUS carries ≤ 500 mA over ~25 mm. Run it against IPC-2152 |
| E5 | MX switch part number | the land is generic Cherry-MX PCB-mount; confirm the switch you actually buy has the same pin positions |
| E6 | USB-C receptacle | the land is HRO TYPE-C-31-M-12 and the BOM says `C165948`, which is that part — confirm at order time that it has not been substituted |
| E7 | button access through the shell | the switches are top-actuated; the enclosure either bores down onto them or reaches over with a flexure tab |

**Basic vs Extended.** Seven unique parts are Basic — every passive plus the
TS-1187A buttons. Six are Extended: the module (`C2913201`), LDO (`C51118`),
mic (`C5656610`), ESD (`C7519`), USB-C (`C165948`) and LED (`C84263`). Whatever
per-part loading fee JLCPCB is charging when you order applies to those six;
check the current fee model on the quote page rather than trusting a number
written here.
