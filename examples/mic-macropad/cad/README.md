# cad — stub

No shell modelled yet. Every number a shell needs is already in
[`constraints.yaml`](constraints.yaml) — outline, mount holes, the USB-C port,
the three key windows on 19.05 mm centres, the mic sound port (a hole in the
shell FLOOR: the ICS-43434 is a bottom-port part), the LED light-pipe bore, and
Espressif's antenna keepout.

Two numbers a shell designer should know before starting: `stack.standoff_h`
is 5 mm and `stack.total_h` is 24 mm, because an MX switch body is 14 mm above
the board before the keycap.
